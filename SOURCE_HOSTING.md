# Source hosting

The canonical repository is on GitHub. To keep the project recoverable if any one
host disappears, the same history is to be mirrored to several other forges.

## Mirror targets

| Host | Planned location |
|------|------------------|
| GitHub (canonical) | https://github.com/SecretSplitKit/Chela |
| GitLab | https://gitlab.com/SecretSplitKit/Chela |
| Codeberg | https://codeberg.org/SecretSplitKit/Chela |
| Bitbucket | https://bitbucket.org/SecretSplitKit/Chela |
| SourceForge | https://sourceforge.net/projects/chela |

## Notes

- GitHub is the source of truth; issues and pull requests are accepted there.
- The other locations are read-only mirrors, pushed from the canonical repository.
- Set the mirrors up before relying on them; this file is the to-do list, not a
  record of mirrors that already exist.
